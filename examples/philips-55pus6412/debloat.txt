# Fingerprint: Philips/PH7M_EU_5596/PH7M_EU_5596:8.0.0/OC/4718:user/release-keys

# Same platform, device and firmware as examples/philips-55pus7503 and examples/philips-65pus8102.
# This list is the 65PUS8102 one checked against `pm list packages -f` on this set: 10 of its entries are
# not installed here (Gameloft, TED and eight NetTV web apps) and three NetTV web apps are only here.
# App labels were read from the APKs with `aapt dump badging`, not guessed from the package name.
# Of 156 packages, 0 were disabled from the factory.

# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/philips-55pus6412/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/philips-55pus6412/debloat.txt com.google.android.tvlauncher

# Stock launcher: com.google.android.tvlauncher (not in this list). On this set Home belonged to the
#                 MAXtv IPTV app (hr.telekom.android.maxtvp) when the list was made, so
#                 build-and-install.sh needs STOCK_LAUNCHER=com.google.android.tvlauncher passed by hand.
# Live TV app:    org.droidtv.playtv
# Launcher config: set live_tv_package to org.droidtv.playtv and add it to hidden_apps.
#
# ADB: USB debugging opens TCP 5555, but the "Allow USB debugging?" dialog never reached the screen
# while a third-party launcher owned Home, even after revoking authorisations and toggling debugging.
# It appeared only after a power cycle at the mains (not standby): connect within ~30 s of port 5555
# opening after boot and accept it on the TV.
#
# Kept on purpose, do NOT disable:
#   org.droidtv.playtv, org.droidtv.xtv, org.droidtv.GlobalKey, org.droidtv.settings, org.droidtv.tvsystemui,
#   org.droidtv.channels, org.droidtv.epgdata, org.droidtv.ci, org.droidtv.teletext, org.droidtv.euinstaller*,
#   com.mediatek.tvinput, com.mediatek.tunerservice, mtktvapi.*: tuner, sources, channels, remote.
#   org.droidtv.alhuewizard, org.droidtv.ambihuecommon: Ambilight + Hue. Ambilight itself lives in the
#   TV engine (dtv_svc) and in org.droidtv.settings, so nothing in this list touches it.
#   org.droidtv.nettvbrowser: HbbTV handler and the Opera engine process (red button on broadcast channels).
#   org.droidtv.eum: user manual; hide it in the launcher instead (disabling it hung the Android 11 Philips).
#   org.droidtv.icp: Philips cloud sign-on used by the NetTV registration below; harmless once those are off,
#   and never exercised disabled on this firmware, so it stays.
#   org.droidtv.contentexplorer: "Media" USB/DLNA browser. org.droidtv.dlna: DLNA renderer.
#   org.droidtv.oad, com.easy.oad (RC FW Update): firmware and remote-control updates.
#   org.droidtv.leanbackcustomizer, com.google.android.tungsten.setupwraith: launcher customiser and setup
#   wizard; setupwraith owns the Wi-Fi network saved in the first-run wizard.
#   com.google.android.apps.mediashell (Chromecast), Play Store, Play Services, com.google.android.tts,
#   com.google.android.tv.remote.service (phone remote app), every streaming app.
#
# Not removable: /vendor/bin/inscape_fp (ACR fingerprinting daemon) is an init service. With the client
# below disabled and persist.sys.droidtv.ACR_Enable=0 (ACR terms never accepted on this set) it collects nothing.
